# Utkarsh Chaudhary — Personal Portfolio Website

Minimalist personal portfolio website built with semantic HTML5, CSS3, and Vanilla JavaScript for the Bosscoder School of Technology Web Development Project.

## Features Implemented (11/11)
1. **Home Section** — Name, minimalist avatar, introduction, welcome message, and quick navigation CTAs
2. **About Me** — Personal bio, focus areas, interests, and goals
3. **Education** — Timeline covering Bosscoder School of Technology (B.Tech CSE AI & ML) and St. Xavier's School
4. **Skills** — Filterable Technical & Non-Technical skills with animated progress bars
5. **Projects** — Project cards with preview images, tech tags, and interactive detail modal
6. **Hobbies & Interests** — Cards with icons and descriptions
7. **Achievements** — Hackathon & competition milestones with certificate preview modal
8. **Contact** — Email copy button, social links, and JS-validated contact form
9. **Dark & Light Mode** — Theme switcher persisted in `localStorage`
10. **Interactive Navigation** — Sticky navbar, smooth scrolling, ScrollSpy active links, and mobile menu
11. **Responsive Design** — Adapts across mobile, tablet, and desktop viewports
